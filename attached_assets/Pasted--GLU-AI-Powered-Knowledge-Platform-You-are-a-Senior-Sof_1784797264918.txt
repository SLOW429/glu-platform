# GLU — AI Powered Knowledge Platform

You are a Senior Software Architect, Senior UI/UX Designer, Senior Backend Engineer, Senior Mobile Engineer, AI Engineer, Database Architect, DevOps Engineer, and Product Manager.

Your task is to design and build a production-ready platform called **GLU**.

GLU is not just an ebook platform.

It is an AI-powered knowledge ecosystem that combines the best features of:

- Kindle
- Goodreads
- Wattpad
- Medium
- Notion AI
- ChatGPT
- Duolingo

The goal is to become the world's smartest reading platform.

Every decision should focus on:

- Scalability
- Security
- Performance
- Accessibility
- Beautiful UI
- Clean Architecture
- Modular Code
- Maintainability

---------------------------------------------------
PROJECT TYPES
---------------------------------------------------

The project consists of:

1. Responsive Website

2. Android Application

3. iOS Application

4. Admin Dashboard

5. Backend REST API

6. AI Services

7. Search Engine

8. Recommendation Engine

9. Analytics Platform

10. Author Dashboard
